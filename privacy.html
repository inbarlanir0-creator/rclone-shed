Privacy policy: rclone shed

rclone shed is used only by its owner, to access the owner's own Google Drive.

  • It reads and writes files in the owner's Google Drive only to copy files between the owner's server and that Drive.
  • No Google user data is shared with, sold to, or transferred to any third party, and it is not used for advertising or any other purpose.
  • Access tokens are stored encrypted in the owner's secrets manager. Access can be revoked at any time at myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
